# docs/ — GitHub Pages site (stage 2)

This directory is the publishing root for the browsable version of the atlas: a searchable
index of the 321 scored predictions, the per-segment maps, and the headline figures, so the
results can be looked at without cloning the repo or running anything.

Hosting is GitHub Pages, which is free for public repositories and needs no domain purchase.
To turn it on once the site exists: **Settings → Pages → Source: `main` / `/docs`**. The site
then lives at `https://<user>.github.io/vesuvius-ink-atlas/`.

Nothing here yet — the repository, data and notebook come first, and a page with no data
behind it is worth less than data with no page.
